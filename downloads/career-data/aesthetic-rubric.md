# Aesthetic Lens 美学评分规范

先识别样本是生成图、馆藏图还是动画。看未压缩呈现或直接打开来源，评估构图等视觉属性。编辑工作台以 1–5 分记录表现，未适用的维度留空。至少选 3 个适用维度。未适用的维度不参与均值，跨样本比较时同时列出适用项。

1 分是严重影响使用，2 分是有多处明显问题，3 分是达到基本要求，4 分是轻微问题，5 分是充分达到约束且有可观察证据。表中例子给出 1–2 分、5 分和需单独判断的边界。3–4 分根据影响范围与主体重要性判定。

| 维度 | 1–2 分反例 | 5 分正例 | 边界与依据 |
| --- | --- | --- | --- |
| 构图合理性 | 主体被无意斩切，画面无清楚焦点 | 主体、空间与留白明确引导视线 | 刻意偏置可成立，结合用途说明 |
| 色彩协调性 | 非预期的杂色压过主体信息 | 主配色有层级且与主题相符 | 高对比海报可刻意用冲突色 |
| 光影表现 | 同一光源下投影方向明显矛盾 | 主体、地面和背景受光关系清楚 | 多光源应找可见灯源或反光 |
| 视觉层次 | 前后景边界融化、主体与背景混同 | 主体、辅助信息及背景有清楚区分 | 扁平版画看形状与明暗组织 |
| 风格一致性 | 人物质感与设定背景无依据地跳变 | 材质、线条及渲染方式服务同一表达 | 拼贴保留有意反差 |
| 画面清晰度 | 主体严重失焦且失去目标信息 | 需要识别的重点细节清楚 | 浅景深或水墨虚化可预期 |
| 主体结构 | 手肢叠接、透视或物件结构不成立 | 关节、连接和比例符合对象定义 | 遮挡处证据不足可不判 |
| 文字与书法 | 要求可读时漏字、混字、笔画形体崩坏 | 可读且字形/字距/笔势与任务匹配 | 草书、异体字需核原作或标不确定 |
| Prompt 符合度 | 遗漏主体、数量或明确布局 | 主体、属性及约束逐条可观察 | 原 Prompt 缺失留空，不能把推测当要求 |
| 生成瑕疵控制 | 有大面积棋盘纹、重复肢体、假水印 | 检查后无影响任务的伪影 | 馆藏裂纹与纸张修补属于原件状态 |
| 视频时序一致性 | 连续镜头同一主体身份突变 | 主体身份、位置和动作在连续帧稳定 | 剪辑切换要与连续帧突变分开 |
| 视频运动自然度 | 接地动作打滑或物体无因瞬移 | 位移、加速度、接触与场景相符 | 卡通形变可接受，须与整体风格一致 |

## 记录与复核

主观偏好单列理由，例如偏爱留白。技术缺陷要记录主体部位、画面位置或时码。不同 Prompt 只比较可公平对照的观察项。源素材不足时用无法判断。示范记录展示评分供校准，导出保留原样本编号、得分、标签、版本和用户复核轨迹。
