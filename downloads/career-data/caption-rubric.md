# Caption Studio 标注与质检规范

先完整观察再写 Caption。中文与英文保留相同主体、动作、关系和时序，自然表达即可。写作顺序为主体 → 动作 → 场景和空间 → 次要视觉特征。用画面左、右避免对象视角混淆。镜头运动与人物运动分别描述。视频记录相对起点的时间区段，跨镜头顺序明确。馆藏标题、作者及年代放来源字段，正文只陈述能从素材确认的内容。

默认范例为“上半部留白，右侧有两列黑色竖书，左下角有红色印记”。不要从画面推定人的职业或动机，也不要把无法读清的文字补成一句古诗。有明显遮挡时写“部分被遮挡”，不能确定左右或动作方向时注明参照对象或省略。视频去音轨的样本不描述声音。色调、构图、风格可作为可见描述，不写主观好坏。

| 质检标签 | 常见错误 | 修订依据 |
| --- | --- | --- |
| 遗漏主体 | 只写背景草地，漏掉画面中央的兔子 | 列出最显著且参与动作的对象 |
| 错误对象 | 把手持物不确定地写成品牌商品 | 退回到可辨认部件或上位类别 |
| 错误动作 | 把角色站定说成跑步 | 核查前后帧、接地与位移 |
| 空间关系错误 | 正对观看者的画面左说成右 | 固定画面视角和参照物 |
| 无依据推断 | 看见人物回头便断言害怕 | 只写转头与面部可见变化 |
| 视频时序错误 | 把 A 后发生的动作写在 A 前 | 按时间点分别观察及核对 |
| 描述不完整 | 只写“风景很好” | 补主体、地点的可见线索和主要动作 |
| 语言表达问题 | 两种语言的数量或否定极性不一致 | 双语交叉回读，核查专名与语义 |
| 标注规范不一致 | 同次任务混用主体视角和画面视角 | 以规范锚点复核并统一格式 |

## 检查与交付

程序检查中文和英文字符、必填、视频时间字段、复制或跨样本重复。编辑可按缺项保存草稿，送审要求通过结构检查。人工复核检查语义事实、时序、双语一致性及重复告警。1 为关键事实相反，2 为明显遗漏，3 为核心事实足够，4 为少量可补细节，5 为完整准确且符合规范。批准和退回都有意见，修改应保留旧版。导出字段包括 sample_id、source、modality、category、caption_zh、caption_en、objects、actions、spatial_relations、quality_score、error_tags、annotation_status、review_status。
