# 项目完成说明 2026年10月15日

本次完成公开数据离线版本，包括标题级AI复核、历史回复评审、SQL交叉分析、证据导出与界面演示。真实API基线、前后版本效果比较、真人双人标注一致性仍未完成，不属于本次成果数字。

## Signal Desk 行动建议

1. 接口错误：区分密钥、权限、供应商兼容、请求参数与网络环境；先完善可操作的错误信息与连接自检，再做真实复现。
2. RAG：拆分上传、解析、索引、检索、引用链路；记录阶段状态与失败原因，分别衡量解析成功、检索覆盖和答案引用可用性。
3. Agent与工具：记录工具调用、参数、返回和最终答案的关联；防止工具失败却显示成功、工具结果丢失和上下文遗漏。
4. 分类质量：优先人工确认74条分歧；不能用两种AI/规则标签一致率替代准确率。

## 指标口径

- 任务成功率=完成预定义验收条件的任务数/有效执行任务数。
- 知识处理成功率=成功解析并完成索引的文件数/有效提交文件数。
- 问题复现率=成功复现的候选问题数/实际尝试复现的问题数。
- 回归通过率=通过验收用例数/适用且有效执行用例数。
- 当前没有以上线上指标的观测数据，不填写虚构结果。
